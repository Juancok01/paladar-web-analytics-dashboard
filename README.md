# 🍔 Paladar - Web Analytics & BI Dashboard

## 📖 Resumen del Proyecto
Este proyecto demuestra la implementación de analítica web end-to-end para el restaurante "Paladar", un cliente de la agencia digital **Monkey Design**. Se desarrolló un menú digital y se rastreó el comportamiento de los usuarios para optimizar la conversión hacia el canal de ventas.

## 🏗️ Arquitectura de Datos
1. **Producto Digital:** Menú interactivo (Frontend).
2. **Tracking (Rastreo):** Configuración de eventos personalizados en **Google Analytics** para medir el tráfico y las interacciones exactas de los clientes.
3. **Visualización (BI):** Dashboard gerencial interactivo construido en **Looker Studio** para monitoreo en tiempo real.

## 📊 Métricas Clave (KPIs) Analizadas
* Total de Visitas al menú digital.
* Tasa de Conversión (Interacciones directas a WhatsApp).
* Flujo de Visitantes por día.
* Embudo de Conversión (Visitas vs. Clics de compra).
